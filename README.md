# Kaskad

**Универсальный скрипт для настройки каскадных соединений, переадресации трафика (NAT) и ускорения сети на Linux.**

Создание «мостов» к VPN (AmneziaWG, WireGuard), прокси (VLESS, XRay) и мессенджерам (MTProto/TProxy) через iptables на промежуточном VPS.

Fork [anten-ka/kaskad](https://github.com/anten-ka/kaskad) (MIT), без рекламы и внешних ссылок автора.

## Требования

- VPS на **Ubuntu** или **Debian**
- Запуск от **root**
- Открытый входящий порт на этом сервере (и доступ к порту на зарубежном сервере)
- IP и порт целевого (зарубежного) сервиса

---

## Возможности

* **Быстрый запуск:** после первой установки команда `kaskad` доступна из любой папки.
* **High Speed Core:** **iptables (kernel NAT)** без лишних процессов.
* **BBR:** включение **Google BBR** для TCP.
* **Протоколы:** UDP (WG/AmneziaWG), TCP (VLESS, VMess, Reality), MTProto/TProxy.
* **Кастомные правила:** разные порты входа и выхода (SSH, RDP и т.д.).
* **Мульти-туннелирование:** несколько правил на разных портах.
* **UFW:** открытие портов при активном firewall; сохранение правил (`netfilter-persistent`).
* **socat relay (IPv4 → IPv6):** проброс трафика от IPv4-клиента на IPv6-сервер; управляется как `systemd`-сервис (автозапуск, перезапуск при сбое).

## Установка

Подключитесь к VPS под `root` и выполните:

```bash
wget -O install.sh https://raw.githubusercontent.com/orangemeduza/kascad/main/install.sh && chmod +x install.sh && ./install.sh
```

Либо склонируйте репозиторий и запустите локально: `chmod +x install.sh && ./install.sh`.

### Последующие запуски

```bash
kaskad
```

## Инструкция: как настроить каскад

Каскад: клиент подключается к **этому** серверу, трафик пересылается на зарубежный хост.

### Шаг 1: Подготовка

Данные **зарубежного** сервера:

* **IP-адрес** (например: `45.10.20.30`)
* **Порт** сервиса

### Шаг 2: Настройка этого сервера

1. Запустите `kaskad`.
2. Выберите протокол или «Кастомное правило».
3. Введите IP и порт(ы).
4. Дождитесь сообщения об успешной настройке.

### Шаг 3: Настройка клиента

1. Откройте клиент (AmneziaWG, v2rayNG, Telegram и т.д.).
2. В **Endpoint / Адрес сервера** укажите **IP этого VPS** (и входящий порт, если порты различаются).
3. Подключитесь.

Цепочка: **Клиент → этот VPS → зарубежный сервер**.

В меню скрипта также есть пункт **«ИНСТРУКЦИЯ»**.

## socat relay: IPv4 → IPv6

Используйте пункты **8–10** меню для схемы:

```
AmneziaWG Client (IPv4:54544) → RU VPS → EUR VPS (IPv6:54544)
```

Скрипт устанавливает `socat` и создаёт `systemd`-сервис вида `kaskad-socat-udp-54544`, который:
- стартует автоматически при загрузке системы;
- перезапускается при сбое (`Restart=always`);
- логируется через `journalctl -u kaskad-socat-udp-54544`.

**Важно для AmneziaWG/WireGuard:** при relay через socat source-адрес пакетов меняется на IP RU VPS — это штатное поведение. Настройте `PersistentKeepalive = 25` на клиенте, чтобы туннель не замерзал.
